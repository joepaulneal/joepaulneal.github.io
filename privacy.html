Privacy Policy

Effective October 4, 2026

This policy covers the Google OAuth app named "Home Assistant" (the "app"), which a single household uses to connect its own Google Nest devices to its own self-hosted Home Assistant server. The app is private and non-commercial.

Data the app accesses

With the device owner's permission, granted on Google's consent screen, the app can access:

  • Google Nest devices the owner selects (Smart Device Management API): thermostat mode, setpoints, temperature, humidity, fan and Eco settings; the doorbell's live stream; doorbell, motion, person and sound events; and event snapshots.
  • Google Cloud Pub/Sub in the owner's own Google Cloud project, used only to create and read the subscription that delivers device events to Home Assistant.

The app does not request access to email, contacts, files, location history, or any other Google data.

How the data is used

Data is used only to display device status and events in the household's own Home Assistant and to run the household's own home automations (for example, a notification when the doorbell rings, or adjusting a thermostat).

Where the data is stored

Device data and recent event snapshots are stored on the household's Home Assistant server, located in the home. Access tokens are stored on that same server. Nothing is stored by this website.

Sharing

Data obtained through Google APIs is not sold, not shared with or transferred to any third party, not used for advertising, and not used to train AI or machine-learning models. It is not accessed by anyone outside the household.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Device states and snapshots are kept on the household's server only as long as Home Assistant's normal history settings retain them. Removing the Nest integration from Home Assistant deletes the stored tokens.

Revoking access

The device owner can revoke access at any time from Google Account → Third-party connections or the Nest Partner Connections Manager.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
